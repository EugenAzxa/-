# Александр - разработка сайтов

Одностраничный сайт-визитка с презентацией услуг и тремя тарифами.
Статика: HTML, CSS и JavaScript без сборки и зависимостей. Открывается как есть.

## Что внутри

```
index.html            вся разметка главной
seo.html              SEO и AI-поиск: скриншоты Search Console и Метрики, раздел AI SEO (id="ai")
assets/css/style.css  стили и адаптив
assets/js/main.js     анимация прокрутки, примеры ниш, вопросы и ответы
assets/img/*.webp     фотографии с убранным фоном
assets/img/seo/       скриншоты для страницы SEO
blog/                 блог (собирается скриптом, руками не править)
_blog/*.md            тексты статей блога, BRIEF.md - правила для новых статей
_tools/build_blog.py  сборка блога, блока «Из блога» на главной, sitemap.xml, robots.txt, llms.txt
_tools/dev.js         локальный сервер с чистыми адресами как на Vercel
assets/film/d2, m2    кадры ролика по прокрутке (d - компьютер 1600px, m - телефон 1280px), poster.webp - последний кадр
```

## Как поменять текст и цены

| Что менять | Где |
|---|---|
| Телефон | найти `79919149854` в `index.html` и заменить везде |
| Имя и подпись в шапке | блок `nav__logo` в `index.html` |
| Цены и состав тарифов | секция `id="tarify"` в `index.html` |
| Примеры ниш в браузере | массив `DEMOS` в начале `assets/js/main.js` |
| Вопросы и ответы | массив `FAQ` в `assets/js/main.js` |
| Строка с услугами | массив `TICK` в `assets/js/main.js` |
| Цвета | переменные в `:root` в `assets/css/style.css` |
| Подписи к ролику | блок `id="ideya"` в `index.html`, тайминги - массив `CAPS` в `main.js` |
| Цифры и скриншоты SEO | `seo.html`, картинки в `assets/img/seo` |

## Как посмотреть локально

```bash
cd rabota-ne-volk
node _tools/dev.js
```

Дальше открыть http://localhost:8123 (адреса чистые, как на Vercel: /seo, /blog, /blog/<статья>)

## Блог

Новая статья: файл `_blog/<адрес-латиницей>.md` с шапкой (slug, title, description, tag), правила в `_blog/BRIEF.md`.
Затем `python3 _tools/build_blog.py` - он соберёт страницу статьи, список в /blog, три карточки на главной
(между маркерами `BLOG:START` и `BLOG:END` в index.html), обновит sitemap.xml, robots.txt и llms.txt.
Адрес сайта для canonical и карты сайта - константа `SITE` в начале скрипта (сейчас работаневолк.рф в punycode).

## Как опубликовать

Всё выкладывается само после `git push` в ветку `main`:

- **Vercel** (https://rabota-ne-volk.vercel.app) - через интеграцию Vercel с GitHub.
- **REG.RU** (https://работаневолк.рф, папка `www/xn--80aacfo5agnheo1a.xn--p1ai/` на хостинге) - через GitHub Actions,
  файл `.github/workflows/deploy-regru.yml`. Заливаются только изменённые файлы, служебные папки
  (`_blog`, `_tools`, `_src`, `.github`, `.vercel`) не попадают на хостинг. Ход выкладки виден во вкладке Actions репозитория,
  там же кнопка «Run workflow», чтобы перезалить вручную.

Для REG.RU в репозитории должны быть секреты (Settings - Secrets and variables - Actions):
`REGRU_FTP_SERVER`, `REGRU_FTP_USER`, `REGRU_FTP_PASSWORD` - данные из панели REG.RU, вкладка «Доступы».

Порядок правки: поменять файлы, при правке статей или меню запустить `python3 _tools/build_blog.py`,
посмотреть локально (`node _tools/dev.js`), затем `git commit` и `git push`.

На хостинге REG.RU настройки сервера лежат в `.htaccess`: чистые адреса (/seo, /blog/slug), кеш картинок,
запрет на служебные папки. Переадресация на https в нём закомментирована до выпуска SSL-сертификата.

## Фотографии

Исходник - студийная съёмка на светлом фоне. Фон убран программно, файлы лежат в `assets/img`:
`face` крупный план, `torso` по пояс, `full` в полный рост, `present` с жестом,
`stand`, `back`, `top`, `profile` - запасные ракурсы.

Чтобы заменить фото, положите PNG с прозрачным фоном под теми же именами и проверьте
доли в массиве `LAYERS` в `assets/js/main.js`: `hw` это ширина кепки относительно ширины
картинки, `hy` и `hx` - положение макушки. По ним кадры совмещаются при отъезде камеры.

## Ролик по прокрутке

Камера заходит в глаз Александра, через зрачок попадает в мозг, где собираются сайты, сайты вылетают из уха и встают рядом с ним.
Сделан в Higgsfield: 5 ключевых кадров на Nano Banana Pro по студийным фото, между ними 4 перехода по 5 секунд в Kling 3.0 pro (1080p, без звука).
На телефоне (экран уже 1.3:1) кадр крупный, но не уже 42% ширины ролика, края растворяются в фоне, а с 80% ролика камера отъезжает до полного кадра.
Ролик склеен и порезан на 301 кадр webp (15 кадров в секунду), страница рисует их на canvas по прокрутке.
Сначала грузится каждый 16-й кадр, потом промежутки, поэтому ролик листается сразу. Цвет края каждого кадра лежит
в строке `FILM_COLS` в `main.js`, по нему меняется фон секции и цвет подписи.

Пересобрать кадры из нового mp4:

```bash
ffmpeg -i full.mp4 -vf "fps=15,scale=1600:-2" -c:v libwebp -quality 74 assets/film/d2/%03d.webp
ffmpeg -i full.mp4 -vf "fps=15,scale=1280:-2" -c:v libwebp -quality 64 assets/film/m2/%03d.webp
```

Если число кадров изменится, поправить `FILM_N` и `FILM_COLS` в `main.js`.
