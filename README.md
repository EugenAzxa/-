# Александр - разработка сайтов

Одностраничный сайт-визитка с презентацией услуг и тремя тарифами.
Статика: HTML, CSS и JavaScript без сборки и зависимостей. Открывается как есть.

## Что внутри

```
index.html            вся разметка страницы
assets/css/style.css  стили и адаптив
assets/js/main.js     анимация прокрутки, примеры ниш, вопросы и ответы
assets/img/*.webp     фотографии с убранным фоном
```

## Как поменять текст и цены

| Что менять | Где |
|---|---|
| Телефон | найти `79919149854` в `index.html` и заменить везде |
| Имя и подпись в шапке | блок `nav__logo` в `index.html` |
| Цены и состав тарифов | секция `id="tarify"` в `index.html` |
| Примеры ниш в браузере | массив `DEMOS` в начале `assets/js/main.js` |
| Вопросы и ответы | массив `FAQ` в `assets/js/main.js` |
| Строка с услугами | массив `TICK` в `assets/js/main.js` |
| Цвета | переменные в `:root` в `assets/css/style.css` |

## Как посмотреть локально

```bash
cd rabota-ne-volk
python3 -m http.server 8123
```

Дальше открыть http://localhost:8123

## Как опубликовать

Проще всего GitHub Pages: в настройках репозитория Settings - Pages - Branch: main, папка `/ (root)`.
Файл `.nojekyll` уже лежит в корне, он нужен, чтобы Pages отдавал папку `assets` как есть.

## Фотографии

Исходник - студийная съёмка на светлом фоне. Фон убран программно, файлы лежат в `assets/img`:
`face` крупный план, `torso` по пояс, `full` в полный рост, `present` с жестом,
`stand`, `back`, `top`, `profile` - запасные ракурсы.

Чтобы заменить фото, положите PNG с прозрачным фоном под теми же именами и проверьте
доли в массиве `LAYERS` в `assets/js/main.js`: `hw` это ширина кепки относительно ширины
картинки, `hy` и `hx` - положение макушки. По ним кадры совмещаются при отъезде камеры.
